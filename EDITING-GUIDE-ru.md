# Как редактировать сайт Angel's через Claude

Основной сайт: https://angelskaraoke.pl/.
Репозиторий: https://github.com/Svip-web/angels-warsaw-site.
Обновления ветки `main` автоматически публикуются на home.pl.
В проекте есть файл `CLAUDE.md` с устройством сайта и правилами изменения меню.

## Самый простой способ: Claude Code в браузере

### Однократное подключение

1. Создай собственный аккаунт GitHub и сообщи его логин владельцу репозитория.
2. Прими приглашение в `Svip-web/angels-warsaw-site` с правом редактирования.
3. Открой https://claude.ai/code в своем аккаунте Claude с доступом к Claude Code.
4. Подключи GitHub и выбери репозиторий `Svip-web/angels-warsaw-site`.
   При настройке доступа приложения Claude выбери только этот репозиторий.
   Если GitHub попросит подтверждение владельца репозитория, передай ему запрос.

### Как вносить очередную правку

1. Начни новую задачу по текущей ветке `main`.
2. Напиши, что нужно изменить. Для новой позиции укажи английское название,
   раздел, цену в zł и при необходимости описание; приложи фотографию.
3. Попроси прочитать `CLAUDE.md`, внести правку, выполнить
   `npm run prepare:site` и `npm run check`, затем создать pull request.
4. Посмотри изменения. Если все верно и проверки GitHub прошли успешно,
   открой pull request и нажми `Merge pull request`, затем подтверди объединение.
5. Дождись успешного `Publish Angel's site to home.pl` в GitHub Actions
   и проверь результат на основном сайте. Если публикация завершилась ошибкой,
   попроси Claude разобрать этот запуск; не считай правку опубликованной.

Пароль от home.pl для этого процесса не нужен: загрузку выполняет
GitHub Actions с уже настроенными секретами.

Пример готового запроса:

> Прочитай CLAUDE.md. В меню кухни в разделе «Закуски» добавь позицию
> [английское название], цена [сумма] zł. Описание: [описание].
> Фото прикреплено. Название оставь на английском; необходимые подписи
> переведи на RU, PL и EN. Сохрани две карточки в ряд на телефоне.
> Выполни npm run prepare:site и npm run check, покажи изменения
> и создай pull request для публикации.

Подключение аккаунтов описано в PUBLISHING-GUIDE-ru.md,
настройки доменов и возврат старого сайта — в HOSTING-STATUS.md.
Доступные способы облачной работы Claude:
https://code.claude.com/docs/en/claude-code-on-the-web.

## Дополнительный способ: Claude Code на компьютере

1. Открой папку проекта в Claude Code.
2. Начни с просьбы прочитать `CLAUDE.md`.
3. Опиши конкретное изменение и приложи новые фотографии или видео.
   Для новой позиции укажи название, цену и раздел.
4. Попроси внести изменение в файлы проекта и показать список изменений.
5. Запусти локальный просмотр из Angels local preview в Claude Desktop
   или командой `npm start`.
   Для этой команды нужен установленный Node.js.
6. Открой главную и меню в браузере. Проверь русский, польский и английский,
   мобильный вид, цену и соответствие фото названию.

Если порт 4173 уже занят, открой PowerShell в папке проекта и выполни

```powershell
$env:PORT = '4174'
node serve.mjs
```

Тогда адрес просмотра — `http://127.0.0.1:4174/`.

## Работа в обычном чате Claude

Прикрепи `CLAUDE.md`, файл, который меняется, и связанные с ним материалы.
Для меню обычно нужны `dist/menu-data.js` и `dist/i18n.js`.
Для изменения карточек приложи также `dist/menu-page.js`,
`dist/menu.html` и `dist/styles.css`.

Попроси вернуть изменённые файлы целиком. Скачай результат и замени
соответствующие файлы в своей локальной папке проекта.
Обычный чат требует этого переноса файлов, чтобы правка появилась
в локальном просмотре.

## Проверка и подготовка результата

Попроси Claude выполнить `npm run check` после правок.
Проверка обнаружит некорректный формат цены, ошибку JavaScript, отсутствующий
файл фото или постер видео. Соответствие цены согласованному меню и фотографии
конкретному блюду нужно проверить отдельно.
Переносы текста и кадрирование дополнительно проверь в браузере.

Чтобы получить готовый комплект, выполни `npm run package` в PowerShell 7.
В папке `releases` появятся два ZIP — сайт для хостинга и проект для Claude.
Упаковка обновляет версии файлов для браузерного кэша.
Следующие шаги подключения публикации описаны в `PUBLISHING-GUIDE-ru.md`.
