# Как редактировать сайт Angel's через Claude

В комплект входят текущие файлы сайта и файл `CLAUDE.md` с устройством проекта.
Архив можно распаковать в отдельную папку на компьютере.
Редактирование и проверка сейчас выполняются локально.

## Работа в Claude Code

1. Открой папку проекта в Claude Code.
2. Начни с просьбы прочитать `CLAUDE.md`.
3. Опиши конкретное изменение и приложи новые фотографии или видео.
   Для новой позиции укажи название, цену и раздел.
4. Попроси внести изменение в файлы проекта и показать список изменений.
5. Запусти локальный просмотр из Angels local preview в Claude Desktop
   или командой `npm start`.
   Для этой команды нужен установленный Node.js.
6. Открой главную и меню в браузере. Проверь русский, польский и английский,
   мобильный вид, цену и соответствие фото названию.

Если порт 4173 уже занят, открой PowerShell в папке проекта и выполни

```powershell
$env:PORT = '4174'
node serve.mjs
```

Тогда адрес просмотра — `http://127.0.0.1:4174/`.

## Работа в обычном чате Claude

Прикрепи `CLAUDE.md`, файл, который меняется, и связанные с ним материалы.
Для меню обычно нужны `dist/menu-data.js` и `dist/i18n.js`.
Для изменения карточек приложи также `dist/menu-page.js`,
`dist/menu.html` и `dist/styles.css`.

Попроси вернуть изменённые файлы целиком. Скачай результат и замени
соответствующие файлы в своей локальной папке проекта.
Обычный чат требует этого переноса файлов, чтобы правка появилась
в локальном просмотре.

## Примеры запросов

> Прочитай CLAUDE.md. В разделе кухни «Закуски» измени цену Antipasti
> на сумму, которую я укажу следующим сообщением. Затем проверь синтаксис
> menu-data.js и покажи результат в локальном меню.

> Прочитай CLAUDE.md. Добавь позицию в меню. Название — [название],
> раздел — [раздел], цена — [сумма] zł, описание — [текст].
> Фото прикреплено. Подготовь его для сайта и проверь мобильную карточку.

> Прочитай CLAUDE.md. Обнови указанный текст на главной и его переводы
> на польский и английский. Проверь переносы строк на телефоне.

## Проверка и подготовка результата

Попроси Claude выполнить `npm run check` после правок.
Проверка обнаружит неправильную цену, ошибку JavaScript, отсутствующее фото
или постер видео и сообщит, какую позицию нужно исправить.
Переносы текста и кадрирование дополнительно проверь в браузере.

Чтобы получить готовый комплект, выполни `npm run package` в PowerShell 7.
В папке `releases` появятся два ZIP — сайт для хостинга и проект для Claude.
Упаковка обновляет версии файлов для браузерного кэша.
Следующие шаги подключения публикации описаны в `PUBLISHING-GUIDE-ru.md`.
