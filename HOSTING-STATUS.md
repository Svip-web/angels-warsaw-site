## Старый сайт и переадресация .com

- До перенаправления `.com` был назначен на
  `/autoinstalator/wordpress` без разделения сервиса. Старый WordPress и его
  база данных не изменялись и сохранены на сервере.
- Для `.com` в панели выбран тип `301 na zewnętrzną domenę`, адрес
  `https://angelskaraoke.pl/`. Обслуживание почты `.com` не менялось.
- `http://angelskaraoke.com/` и `http://www.angelskaraoke.com/` проверены:
  отвечают 301 с переходом на новый HTTPS-сайт `.pl`.
- Для `https://angelskaraoke.com/` остается проблема отсутствующего
  сертификата именно для `.com`: браузер проверяет TLS до выполнения 301.
  Сертификат `.pl` эту проблему не решает. Покупки не выполнялись.
- Для восстановления показа старого сайта на `.com` вместо переадресации
  в панели нужно вернуть `Podkatalog bez separacji serwisu` и путь
  `/autoinstalator/wordpress`. Файлы и базу данных переустанавливать не нужно.

## DNS-кеш

После первого переключения обнаружена дополнительная причина показа Tilda:
в зоне `.pl` оставались два ручных NS-записи `ns1.tildadns.com` и
`ns2.tildadns.com` с TTL 3600 наряду с серверами home.pl. Оба лишних NS
удалены из панели home.pl. После изменения в зоне 9 записей, ссылок на Tilda
нет; запись A указывает на `46.242.243.40`. Поставщик DNS использует
`dns.home.pl`, `dns2.home.pl`, `dns3.home.pl`. Для `.com` смешанных NS нет.

Часть рекурсивных DNS еще хранит прежний список NS и адрес `5.181.161.73`.
До истечения кеша в таких сетях может показываться старая страница Tilda 402.
По свежим A-ответам Google/Cloudflare новый адрес уже home.pl. Сам новый
сервер отдельно проверен с правильным IP и строгой проверкой сертификата:
HTTPS отвечает 200. Доступ и оплата Tilda для работы нового сайта не нужны.

GitHub Pages продолжает работать независимо от основного домена.
